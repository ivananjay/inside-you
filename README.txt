INSIDE YOU — Website Prototype

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder inside-you-website.
3. Klik dua kali index.html, atau buka folder di VS Code lalu jalankan dengan Live Server.

STRUKTUR
- index.html : struktur halaman
- style.css  : tampilan, warna, layout, responsive
- script.js  : interaksi mood check-in, jurnal, quiz, topik, reminder, checklist, dan guest dialog

CATATAN
- Jurnal menggunakan localStorage browser pada perangkat yang sedang dipakai. Data tidak tersinkron ke perangkat lain dan dapat hilang jika data browser dihapus.
- Login masih berupa demo guest access, belum ada autentikasi/server.
- Prototype ini bukan alat diagnosis atau pengganti konseling profesional.
- Referensi ayat ditampilkan sebagai pengingat; periksa kembali terjemahan dan konteks dengan mushaf/tafsir tepercaya sebelum publikasi.
